# Pre-Submission Checklist

Use before each stage zip and before **S6 final**.

## Design

- [ ] ER diagram has entities, attributes, keys, cardinalities
- [ ] Functional dependencies documented
- [ ] Normalization demonstrated (1NF–BCNF where applicable)
- [ ] Assumptions and stakeholder conflicts recorded (S1)

## Implementation

- [ ] DDL executes successfully on chosen DBMS
- [ ] Seed data is meaningful (not 3 fake rows)
- [ ] CRUD tested through application / API / CLI
- [ ] GitHub repository updated with stage tag

## Advanced database (S4+)

- [ ] At least one meaningful **view**
- [ ] At least one **stored procedure or function**
- [ ] At least one **trigger**
- [ ] **Transaction** scenario demonstrated
- [ ] **Concurrency** scenario demonstrated (script or graph)
- [ ] **RBAC** implemented
- [ ] **SQL injection** defense demonstrated (parameterized queries)

## Optimization (S5+)

- [ ] Index strategy documented
- [ ] EXPLAIN / EXPLAIN ANALYZE evidence included
- [ ] Before/after benchmarking included (timings, not slogans)

## Academic integrity

- [ ] Contribution log updated
- [ ] AI Usage Note updated
- [ ] Peer ratings current (S7)
- [ ] Stage reflection written

## Final (S6)

- [ ] Final report complete per [final-report-outline.md](final-report-outline.md)
- [ ] Demo rehearsed; every member has a speaking part
- [ ] `pre-submission-checklist.md` copied into submission zip root
