# ER Design Checklist

Before **S2** submission:

- [ ] 8–10+ entities (domain objects, not screens)
- [ ] Every entity has a candidate key identified
- [ ] Weak entities use partial keys + identifying owner (if any)
- [ ] Relationships show cardinality **and** participation
- [ ] Relationship attributes placed on correct relationship
- [ ] ISA/EER used only with disjoint/overlap/total/partial noted
- [ ] Multi-valued attributes decomposed in mapping plan
- [ ] Assumption log updated
- [ ] Diagram readable in PDF (notation consistent)
- [ ] Peer review completed
