# Student Rubric (100 marks)

You are assessed on evidence, not on slide polish alone. `SELECT *` does not count as a query.

| Component | Max | Excellent | Unacceptable |
| --- | ---: | --- | --- |
| M1 Requirements | 10 | Stakeholders, rules, data needs that force a schema | Copied problem paragraph, no rules |
| M2 ER | 15 | Keys, cardinalities, weak entities, constraints justified | UI boxes, missing keys, no participation |
| M3 Normalization | 15 | FDs, anomalies, 1NF–BCNF proof | “We are in 3NF” with no FD |
| M4 SQL | 20 | ≥20 question-driven queries; joins, aggregates, nested, views | Twenty `SELECT *` clones |
| M5 Tx / CC / opt | 15 | Schedule, graph, ACID, index + EXPLAIN | Screenshots with no graph |
| Final package | 15 | Integrated, honest AI log, contributions | Missing schema or fake data |
| Presentation / viva | 10 | Every member explains a query and a constraint | One speaker, others silent |
