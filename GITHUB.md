# GitHub

This folder is a complete course repository (same week/session layout as Programming in Java).

```text
git init
git add .
git commit -m "Add DBMS CSL0311[T] course portal"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

Do not commit filled marks sheets. Form URLs in `config/submission-links.json` may stay empty until you create forms.

GitHub Pages: Settings → Pages → `main` `/ (root)` → `index.html`.
