# Course Outcomes

**Course:** Database Management System (CSL0311[T])

Every session lists which outcomes it contributes to.

---

## CO1

Understand and implement modern database concepts and AI-assisted DB modeling/design.

**Bloom level:** BL2 — Understand

**Where it is built:** Unit 1, AI-assisted ER/schema sessions, cloud-native and distributed introductions, SQL copilots as exposure

---

## CO2

Understand and implement databases using:

- SQL
- Relational Algebra

**Bloom level:** BL3 — Apply

**Where it is built:** Unit 2, SQL labs, Milestone 4, RA problem sets

---

## CO3

Design and fine-tune efficient databases using normalization principles.

**Bloom level:** BL4 — Analyze

**Where it is built:** Unit 3, Milestone 3, anomaly analysis, BCNF proofs

---

## CO4

Understand and apply:

- transactions
- concurrency control
- distributed database concepts

**Bloom level:** BL4 — Analyze

**Where it is built:** Unit 1 (distributed preview), Unit 4, Unit 5, Milestone 5, precedence-graph labs

---

## CO5

Design and implement databases for real-life intelligent database applications.

**Bloom level:** BL5 — Evaluate

**Where it is built:** PBL spine (Milestones 1–Final), query analytics, integrity constraints under conflict

---

## Unit mapping

```text
Unit 1  →  CO1 (primary), CO4 (distributed / cloud preview)
Unit 2  →  CO2 (primary), CO1 (NL-to-SQL exposure)
Unit 3  →  CO3
Unit 4  →  CO4
Unit 5  →  CO4, CO5
PBL     →  CO1, CO2, CO3, CO4, CO5 (progressive)
```
