# Instructor Guide

## Session Objective

Students use ∪ ∩ − and one division idea, write a 3-step RA query, and decode one TRC and one DRC expression.

## Course Outcome Mapping

```text
CO2  Set operations, RA queries, TRC/DRC overview
```

## Flow

```text
0–8 min     Union-compatible
8–25 min    Difference and “never”
25–38 min   Division as “for all”
38–50 min   TRC vs DRC one example each
50–60 min   Exit; M2 review is S12
```

## Exit Question

Write algebra for students who applied for a scholarship but were not allotted funds (PBL 05).
