# Instructor Guide

## Session Objective

Students write schemas with PK/FK, entity and referential integrity, and finish ER-to-relational on a weak entity.

## Course Outcome Mapping

```text
CO2  Relational structure; ER to relational
```

## Flow

```text
0–8 min     Relation as a set
8–25 min    Keys ladder
25–45 min   Live mapping Hostel–Room–Resident
45–55 min   1:1 placement drill
55–60 min   Exit
```

## Exit Question

Define candidate key and foreign key using Room and Hostel in four sentences.
