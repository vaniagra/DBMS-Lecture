# Instructor Guide

## Session Objective

Students can draw ISA with disjoint/overlap and total/partial, and one aggregation example, tied to a campus rule.

## Course Outcome Mapping

```text
CO1  Extended ER features
```

## Flow

```text
0–8 min     Person / Student / Faculty hook
8–25 min    ISA constraints
25–40 min   Aggregation on board
40–52 min   Pair: PBL 07 invigilator rule
52–60 min   Exit
```

## Board Plan

PERSON ISA with two subclasses; label **disjoint, partial** unless the class chooses otherwise.

## PBL connection

If the team has no ISA, they must write “no specialization; reason.”

## Exit Question

State two EER constraints for Student/Faculty in four sentences.
