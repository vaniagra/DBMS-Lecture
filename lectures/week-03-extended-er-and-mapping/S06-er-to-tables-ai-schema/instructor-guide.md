# Instructor Guide

## Session Objective

Students can reduce a small ER to a relational schema by rule, then critique an AI-generated schema using the same rules.

## Course Outcome Mapping

```text
CO1  ER to tables; AI-assisted schema; prompt-driven ER
```

## Flow

```text
0–8 min     Hook: AI forgot unique unit_id
8–28 min    Mapping rules, live on Hostel–Room–Resident
28–40 min   ISA mapping options (do not finish all textbooks)
40–52 min   Prompt demo; students must reject Login entity
52–60 min   Exit
```

## AI activity

One projected prompt. Students mark accept/reject. No copy-paste into Milestone 2 without redraw.

## Exit Question

Write the table and keys for a weak entity in four sentences.
