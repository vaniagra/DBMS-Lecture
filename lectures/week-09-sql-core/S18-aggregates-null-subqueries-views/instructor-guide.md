# Instructor Guide

## Session Objective

Students write GROUP BY/HAVING, one IS NULL query, one nested query, one derived table, one VIEW.

## Course Outcome Mapping

```text
CO2  Aggregates, NULL, nested, derived relations, views
```

## Flow

```text
0–8 min     0 vs NULL ratings
8–22 min    GROUP BY / HAVING
22–38 min   Nested + correlated one example
38–50 min   CREATE VIEW for kiosk
50–60 min   Exit
```

Why does `WHERE leftover_kg = NULL` return no rows?
