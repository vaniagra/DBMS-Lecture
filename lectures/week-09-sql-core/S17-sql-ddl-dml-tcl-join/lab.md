# Lab: Schema and Joins

## Dialect

PostgreSQL. ANSI where possible.

## Tasks

1. `schema.sql`: at least four tables with PK/FK/CHECK.
2. INSERT 8–12 rows.
3. Five queries: inner join, left join unmatched, UNION, EXCEPT or NOT IN, self-join **or** three-table join.
4. Predicted result for query 3 **before** execute.

## Forbidden as “a query”

`SELECT * FROM t;`
