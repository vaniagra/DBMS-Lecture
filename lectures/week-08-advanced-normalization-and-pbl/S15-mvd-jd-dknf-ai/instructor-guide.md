# Instructor Guide

## Session Objective

Students can define MVD, JD, DKNF at overview depth, name an alternative design path, and run a data-quality checklist on sample rows.

## Course Outcome Mapping

```text
CO3  MVD, JD, DKNF, alternatives, AI NF/anomaly, data quality
```

## Flow

```text
0–8 min     Independent skills and languages
8–22 min    MVD
22–32 min   JD one picture
32–42 min   DKNF as “keys and domains”
42–52 min   AI false BCNF
52–60 min   Exit
```

## Exit Question

Give one MVD in English from a campus table.
