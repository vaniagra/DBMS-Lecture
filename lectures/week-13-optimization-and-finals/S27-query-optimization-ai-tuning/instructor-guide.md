# Instructor Guide

## Session Objective

Students run EXPLAIN on one JOIN, add one index, compare, and reject one useless index.

## Course Outcome Mapping

```text
CO4  Query optimization
CO5  Intelligent application: measured tuning
```

## Flow

```text
0–8 min     Declarative SQL
8–25 min    Live EXPLAIN ANALYZE
25–42 min   CREATE INDEX and re-run
42–52 min   AI suggestion critique
52–60 min   Exit
```
