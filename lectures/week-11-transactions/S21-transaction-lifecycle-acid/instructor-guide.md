# Instructor Guide

## Session Objective

Students can draw the lifecycle, map ACID to a double-allocation story, and write a BEGIN/COMMIT skeleton.

## Course Outcome Mapping

```text
CO4  Transactions, lifecycle, ACID, implementation intro
```

## Flow

```text
0–8 min     Crash between UPDATE and INSERT
8–20 min    Lifecycle
20–38 min   ACID table
38–50 min   Live BEGIN/COMMIT (PostgreSQL)
50–60 min   Exit
```

## Exit Question

Which ACID property is “two clerks, one last bed”?
