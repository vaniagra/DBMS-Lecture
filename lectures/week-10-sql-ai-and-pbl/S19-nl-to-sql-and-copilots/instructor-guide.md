# Instructor Guide

## Session Objective

Students run one NL-to-SQL cycle, catch one join bug, and write a declaration row.

## Course Outcome Mapping

```text
CO1  AI-assisted modeling/SQL exposure
CO2  SQL they can still explain
```

## Flow

```text
0–8 min     Policy reminder
8–20 min    Live bad INNER JOIN
20–40 min   Students: own SQL vs tool
40–52 min   Declaration template
52–60 min   Exit; S20 is live SQL demo
```

## If tools are blocked

Use a printed wrong query as “the copilot.” Same pedagogy.

## Exit Question

Name two ways NL-to-SQL commonly breaks LEFT JOIN meaning.
