# Instructor Guide

## Session Objective

Students write BEGIN/COMMIT, name isolation levels, and explain CAP with a partition story. They must not “choose BASE” for bed allocation.

## Course Outcome Mapping

```text
CO4  SQL tx, BASE, CAP, distributed tx, eventual consistency
```

## Flow

```text
0–10 min    Live ROLLBACK
10–25 min   Isolation phenomena
25–40 min   CAP two-campus
40–50 min   2PC named only
50–60 min   Exit
```

## Exit Question

Give one operation that must not be eventually consistent in PBL 09.
