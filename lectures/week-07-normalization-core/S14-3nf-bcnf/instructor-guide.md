# Instructor Guide

## Session Objective

Students detect transitive FDs, prove 3NF, and run one BCNF counterexample where a dependency is lost.

## Course Outcome Mapping

```text
CO3  3NF, BCNF
```

## Flow

```text
0–8 min     Advisor office story
8–25 min   3NF definition + proof template
25–42 min   BCNF vs 3NF classic
42–55 min   Lossless check
55–60 min   Exit
```

## Exit Question

Give one FD that 3NF allows and BCNF forbids.
