# Instructor Guide

## Session Objective

Students compute FDs, name three anomalies, and decompose to 2NF on a composite-key table.

## Course Outcome Mapping

```text
CO3  Good design, FD, anomalies, 1NF, 2NF
```

## Flow

```text
0–8 min     Bad leftover table
8–22 min    FD definition, keys from FDs
22–38 min   Anomalies
38–52 min   1NF then 2NF live decompose
52–60 min   Exit
```

## Exit Question

Why does a surrogate `id` not fix `roll → name` stored on Enroll?
