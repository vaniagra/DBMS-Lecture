# Database Management System — Curriculum Overview

CSL0311[T] · Theory · 2-0-0 · 16 weeks · two 50–60 minute lectures per week

Each week folder contains session folders. Each session has `student-reference.md`, `instructor-guide.md` and `lab.md`.

Delivery is PBL-aligned. Official unit numbers stay on every file. No syllabus topic is dropped.
